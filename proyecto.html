Proyecto Integrador

Experimenta en vivo el funcionamiento de la red social interactiva desarrollada durante el primer año académico.

Red Social Tipo "FriendSpace"

Esta demostración emula en tiempo real la lógica programada para el proyecto integrador. El código original utilizaba MySQL para la base de datos de usuarios y amigos, y HTML/CSS para la capa visual.

El desarrollo se enfocó en comprender el flujo completo de una aplicación interactiva que realiza consultas relacionales en la base de datos a partir de interacciones directas del usuario final.

Prueba las siguientes características en el mockup del teléfono:

  • Aceptar Amigos: Simula la gestión de amistad con solicitudes entrantes en la barra superior del header.
  • Escribir y Publicar: Escribe una publicación en el campo de texto y haz clic en "Publicar" para agregarla dinámicamente en el feed.
  • Reacciones Interactivas: Presiona el botón de "Me gusta" para interactuar y ver las actualizaciones lógicas de los contadores.
  • Sección de Comentarios: Redacta comentarios directamente y presiona Enter para verlos renderizados al instante.
