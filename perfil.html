Perfil de Egreso

Capacitado para desarrollar soluciones informáticas integrales y eficientes a través de metodologías actuales.

Como técnico analista programador soy un profesional altamente capacitado para desarrollar soluciones informáticas mediante el uso de lenguajes de programación modernos, diseño y modelamiento de bases de datos, y diversas herramientas tecnológicas.

Estoy completamente preparado para analizar detalladamente requerimientos de clientes, diseñar sistemas de software modulares y participar activamente en el ciclo completo del desarrollo de software, desde su etapa de levantamiento inicial hasta su despliegue y soporte final.

Durante mi formación, he adquirido sólidas competencias en programación estructurada y orientada a objetos, desarrollo web dinámico, administración de bases de datos relacionales y configuración de entornos de trabajo virtualizados. Esto me capacita para enfrentar problemas tecnológicos y proponer soluciones eficientes, escalables e innovadoras para las organizaciones actuales.

Programación

Sólidos fundamentos de lógica computacional y POO en JavaScript y Python.

Desarrollo Web

Maquetación responsiva, CSS estructurado e interfaces dinámicas con interactividad.

Bases de Datos

Modelamiento relacional de entidades, consultas complejas e indexado con MySQL y SQL Server.

Sistemas y Entornos

Administración de consola (DOS), entornos locales (VSC) y entornos virtualizados para despliegues.
